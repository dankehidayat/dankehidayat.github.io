This project was another prototype design for my upcoming project in East Luwuh that involves pepper agriculture. However, there has been no latest update regarding the proposed project, so it's on hold for now.

This project is very simple and straightforward. It uses 3 cheap soil moisture sensors and a BMP280 sensor that can measure the humidity and even pressure. We can calculate the altitude based on the pressure, and it's quite decent, not so accurate, but it works.

As of when I'm writing this, at 26/09/26, the electronic and the sensors are inactive. But just for fun, I'm planning to revamp the UI/UX for better looks, unlike the discontinued but still live project, Flowpoint.
