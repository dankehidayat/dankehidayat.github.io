## Validation notes

- **Abandoned hosts** (not retried, no substitute URLs used): `digitalcollections.nypl.org` (Incapsula scrape block), `unsplash.com` (HTTP 401 bot challenge), `wikimedia.org` / `upload.wikimedia.org` (prior), `rawpixel.com` (prior).
- **NYPL source pages** use `old-digitalcollections.nypl.org` (observed 200) because `digitalcollections.nypl.org` is blocked. Image IDs 1155054 and 1155051 were confirmed present on the respective item pages by plain GET of the HTML.
- **Köhler source page**: `http://www.biolib.de/koehler/EICHE.html` and `.../MOHN.html` returned 404 earlier and are not used; `index.html` (200) is the canonical plate index and links both `.jpg` files.
- **Paper texture**: only the direct `images.unsplash.com` CDN URL is listed (validated 200). No Unsplash HTML page URL is included because `unsplash.com` could not be validated.
- All eight original local files verified as non-empty JPEG (`file` → `image/jpeg`); dimensions measured with `sips`.
- **2026-09-25 lily batch**: no species duplicates the earlier eight plates (*L. martagon*, *L. pomponium* excluded). Curtis plates were taken from the `Original` (`/or/…`) free-images.com size (1827x3180 / 1854x3276, ~720 KB) and re-encoded locally to WebP q70 (`cwebp`) at full resolution: 354 KB and 306 KB. The three Redouté plates were saved as-is from `images.nypl.org/?id=…&t=w` (490–499 x 760 px, 31–118 KB JPEG). Size guesses for larger NYPL variants (`t=l`, `t=orig`, `t=full`, `t=hi`, `t=tif`) returned 404 and were discarded without retry; only the `t=w` URLs listed above are used. Source species were confirmed from the NYPL item page titles and the free-images.com “Keywords from Image Description” blocks (pl. 280 = *Lilium candidum*, pl. 261 = *Lilium catesbaei*).
- Manifest for the pages lane: `src/assets/images/folio/extra-lilies.json` (`file`, `species`, `alt`, `credit`). No page/data/component files were modified by this batch.
